# CPU RAM GPU Mini

A small and lightweight Rainmeter skin for monitoring CPU, RAM and GPU usage directly from the Windows desktop.

## Preview

![CPU RAM GPU Mini Preview](Preview.png)

## Features

- Displays CPU usage.
- Displays RAM usage.
- Displays GPU usage.
- Compact and minimal design.
- Transparent background.
- Lightweight desktop monitoring.
- Values update automatically.

## Installation

1. Install Rainmeter.
2. Download the latest version from the Releases section.
3. Extract the downloaded ZIP file.
4. Copy the `CPU_RAM_GPU_Mini` folder to:

   `Documents\Rainmeter\Skins`

5. Open Rainmeter.
6. Click **Refresh all**.
7. Load the skin from:

   `CPU_RAM_GPU_Mini`

## Requirements

- Windows 10 or Windows 11
- Rainmeter 4.5 or newer
